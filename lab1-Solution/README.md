# RMPC-lab1

First laboratory work for the course **Robot Motion Planning and Control**.

## Assignment overview
The purpose of this work is to study the kinematic and dynamic characteristics of a serial manipulator using Robotics Toolbox for Python.  
A robot model different from **Puma560** was selected, and its kinematic and dynamic properties were analyzed.

## Selected robot
The selected robot is the **Stanford manipulator** from Robotics Toolbox for Python.  
This choice satisfies the assignment requirement because it is different from **Puma560**.

## Assignment tasks completed

### 1. Manipulator model and DH parameters
The Stanford manipulator model was loaded from the toolbox.  
Its Denavit-Hartenberg parameters were extracted and displayed in tabular form.

### 2. Dynamic parameters of the links
The following dynamic parameters were specified for all links:
- mass of each link
- center of mass of each link
- inertia tensor of each link
- moment of inertia of the drive
- viscous friction coefficient
- Coulomb friction coefficient
- gear ratio
- joint limits

### 3. Initial and final robot configurations
Arbitrary initial and final robot configurations were selected within the allowed joint limits.  
Both configurations were displayed graphically.

### 4. Trajectory planning
A trajectory between the initial and final configurations was planned in joint space using the prebuilt function `jtraj`.  
The resulting joint positions, velocities, and accelerations were obtained.

### 5. Inverse dynamics
The inverse dynamics problem was solved using the Newton-Euler method for three cases:
1. non-zero velocities and accelerations
2. non-zero velocities and negligible accelerations
3. zero velocities and accelerations

The corresponding joint torques were calculated along the whole trajectory.

### 6. Components of the dynamic equation
The following components of the manipulator dynamic equation were obtained:
- inertia matrix \( M(q) \)
- Coriolis/centrifugal matrix \( C(q,\dot{q}) \)
- gravity vector \( G(q) \)

These quantities were computed for all time samples along the trajectory.  
For brevity, selected numerical values were displayed for the first, middle, and final instants.

### 7. Graphs
The torque plots of all manipulator joints were obtained for the three considered scenarios.  
These graphs illustrate the variation of joint torques along the planned trajectory.

## Main conclusions
1. The Stanford manipulator model satisfies the assignment requirement because it is different from Puma560.
2. The DH parameters fully describe the kinematic structure of the robot.
3. The trajectory generated by `jtraj` provides smooth profiles of position, velocity, and acceleration.
4. The first inverse dynamics case gives the highest torques because both velocity and acceleration effects are included.
5. The second case gives lower torques because the acceleration term is neglected.
6. The third case mainly represents the torques required to maintain the robot configuration against gravity.
7. The matrices \( M(q) \), \( C(q,\dot{q}) \), and \( G(q) \) vary along the trajectory and describe the dynamic behavior of the manipulator.
